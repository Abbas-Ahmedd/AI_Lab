# K-Means Clustering from Scratch

This project contains a simple implementation of the K-Means Clustering Algorithm using Python without using external machine learning libraries.

## Features

- Euclidean Distance Calculation
- Assigning points to nearest centroid
- Updating centroids
- Multiple iterations until convergence
- SSE (Sum of Squared Errors)
- Predicting new data points
- Works with 2D and 3D datasets
