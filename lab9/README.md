# Neural Network Implementation in Python

This project demonstrates a simple implementation of a Neural Network using Python.

The notebook covers the basic concepts of artificial neural networks including neurons, weights, activation functions, forward propagation, and training processes.

---

## Features

- Basic neural network implementation
- Forward propagation
- Weight initialization
- Activation functions
- Error calculation
- Training process
- Prediction using trained model
- Understanding neural network workflow

---

## File Structure

```bash
lab9.ipynb
```

---

## Topics Covered

### 1. Neurons and Weights
Understanding how neurons process input values using weights and biases.

### 2. Activation Functions
Applying activation functions to introduce non-linearity.

### 3. Forward Propagation
Passing inputs through layers to generate outputs.

### 4. Error Calculation
Measuring prediction error during training.

### 5. Training Process
Updating weights to improve model performance.

### 6. Prediction
Using the trained network to predict outputs for new data.
