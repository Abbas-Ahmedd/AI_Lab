# Genetic Algorithm Implementation in Python

This project demonstrates a simple implementation of a Genetic Algorithm (GA) using Python.

The notebook covers the core concepts of genetic algorithms including chromosome creation, fitness evaluation, selection, crossover, mutation, and optimization experiments.

---

## Features

- Random chromosome generation
- Fitness function implementation
- Parent selection
- Single-point crossover
- Mutation operation
- Complete genetic algorithm workflow
- Experiments with:
  - Mutation rate
  - Population size
  - Crossover rate
- Target string matching challenge

---

## File Structure

```bash
lab8.ipynb
```

---

## Topics Covered

### 1. Chromosome Creation
Generate random binary chromosomes.

### 2. Fitness Function
Evaluate how good a chromosome is based on predefined criteria.

### 3. Parent Selection
Select chromosomes for reproduction based on fitness.

### 4. Crossover
Combine two parents to create offspring using single-point crossover.

### 5. Mutation
Randomly modify genes to maintain diversity.

### 6. Full Genetic Algorithm
Run multiple generations to evolve better solutions.

---

## Experiments

The notebook includes experiments to study the effect of:

- Mutation Rate
- Population Size
- Crossover Rate

These experiments help understand how different parameters affect convergence and performance.

## Challenge Task

A target string matching problem is implemented using a genetic algorithm to evolve strings toward a desired target.
